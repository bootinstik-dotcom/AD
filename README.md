# Boostly Ads Telegram Bot

ربات تبلیغات تلگرامی با Python + aiogram 3.32 و SQLite؛ با دکمه‌های Reply Keyboard دارای ایموجی پریمیوم و رنگ، بدون Supabase و Webhook و پورت HTTP.

## تنها متغیر محیطی
`TELEGRAM_BOT_TOKEN` = توکن ربات از BotFather

شناسه مالک و توسعه‌دهنده در سورس تنظیم شده‌اند:
- Owner: `8292338949`
- Developer: `858897695`

## استقرار روی Railway
1. همه فایل‌های ZIP را مستقیماً در ریشه مخزن GitHub قرار بده (پوشهٔ اضافی ندارد). سپس پروژه را در GitHub قرار بده و در Railway از آن Deploy بگیر.
2. در سرویس Railway فقط متغیر `TELEGRAM_BOT_TOKEN` را اضافه کن.
3. از Settings سرویس، یک **Volume** بساز و Mount Path را دقیقاً `/data` قرار بده.
4. Deploy کن.
5. در تلگرام `/start` را برای ربات بفرست.

**مهم:** Volume ضروری است. بدون Volume، فایل SQLite ممکن است با حذف کانتینر یا Deploy مجدد از بین برود. کد دیتابیس را در `/data/adservice.sqlite3` نگه می‌دارد.

## دستورات مالک
- `/start` منوی اصلی
- `/backup` ارسال بکاپ دیتابیس در تلگرام
- `/setgroup -100...` تنظیم گروه گزارش‌ها
- `/removeadmin` شروع حذف مدیر
- `/id` نمایش شناسه عددی تلگرام

## قابلیت‌ها
- دو دسته تبلیغات گروه و چنل
- چهار محصول اولیه: جوین اجباری و بنر ۲۴ ساعته برای هر دسته
- افزودن پکیج از پنل مالک
- افزودن روش پرداخت رمزارزی از پنل مالک
- ثبت سفارش و اطلاعات تبلیغ
- ثبت TXID و رسید
- بررسی دستی پرداخت توسط مدیر
- تغییر وضعیت سفارش
- چند مدیر، گزارش کلی و تیکت پشتیبانی
- گزارش به مدیران و گروه خصوصی اختیاری

## دکمه‌های پریمیوم و رنگی
- دکمه‌ها از `icon_custom_emoji_id` و `style` در Telegram Bot API 9.4+ استفاده می‌کنند.
- برای نمایش ایموجی سفارشی، مالک ربات باید Premium فعال داشته باشد یا ربات شرایط خرید نام کاربری اضافه در Fragment را داشته باشد.
- رنگ دکمه‌ها از سه سبک آبی (`primary`)، سبز (`success`) و قرمز (`danger`) انتخاب می‌شود.
- برای پشتیبانی از این فیلدها، aiogram به نسخه 3.32.0 ارتقا داده شده است.

## نکات مهم
- قیمت و پکیج اولیه عمداً ساختگی نیستند؛ مالک باید از پنل پکیج واقعی تعریف کند.
- تأیید پرداخت دستی است؛ ربات ادعای تأیید بلاکچین نمی‌کند.
- Long Polling استفاده می‌شود؛ Webhook و PORT لازم نیست.
- FSM مکالمه در حافظه است؛ اگر هنگام تکمیل فرم ربات Restart شود، مکالمه جاری از ابتدا شروع می‌شود، اما سفارش‌ها و داده‌های ثبت‌شده در SQLite باقی می‌مانند.
- قبل از استفاده واقعی، یک سفارش آزمایشی و بکاپ را تست کن.


## ساختار فایل‌ها
تمام فایل‌های اجرایی مستقیماً در ریشه پروژه قرار دارند و پوشه app وجود ندارد. دیتابیس SQLite روی Volume مسیر `/data` ذخیره می‌شود.
